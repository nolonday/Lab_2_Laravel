# Учебный сайт на Laravel

Учебный проект по серверной веб-разработке. На сайте реализованы страницы на Laravel с общим Blade-макетом, маршрутизацией и выводом публикаций из JSON-файла.

## Реализовано

- Общий макет с меню, основной областью и подвалом.
- Главная страница со списком публикаций из `public/articles.json`.
- Контроллер `MainController`, который читает JSON и передает данные в Blade-шаблоны.
- Страница галереи для каждой публикации: полное изображение, дата и описание.
- Переход к публикации по нажатию на изображение-превью или заголовок.
- Страницы «О нас» и «Контакты».
- Адаптивное оформление сайта.

## Страницы

| Адрес | Содержание |
| --- | --- |
| `/` | Список публикаций |
| `/galery/{article}` | Публикация и полноразмерное изображение по индексу в JSON |
| `/about` | Информация о проекте |
| `/contacts` | Контактные данные |

## Данные и изображения

Файл `public/articles.json` содержит публикации и имена файлов изображений. Изображения-превью (`preview.jpg`, `preview_2.jpg`) и полные изображения (`full.jpeg`, `full_2.jpeg`) размещаются в папке `public`.

## Запуск

Требуются PHP 8.3 или новее и Composer.

```bash
composer install
php artisan serve
```

Откройте адрес, указанный Artisan (обычно `http://127.0.0.1:8000`).

Для запуска тестов:

```bash
php artisan test
```
